# Portfolio Website

A modern, minimal portfolio website built with Jekyll, inspired by the Lever resume theme.

## Features

- 🎨 Modern, clean design
- 📱 Fully responsive
- 🌙 Dark mode support
- ⚡ Fast performance
- 📝 Blog functionality
- 🎯 SEO optimized
- 🚀 GitHub Pages ready

## Getting Started

### Prerequisites

- Ruby 2.5.0 or higher
- Bundler gem

### Installation

1. Clone the repository:
```bash
git clone https://github.com/jackshee/jackshee.github.io.git
cd jackshee.github.io
```

2. Install dependencies:
```bash
bundle install
```

3. Build and serve locally:
```bash
bundle exec jekyll serve
```

4. Visit `http://localhost:4000` in your browser

## Customization

### Site Configuration

Edit `_config.yml` to customize:
- Site title and description
- Author information
- Social media links
- Navigation menu
- Colors and fonts

### Content

- **Homepage**: Edit `index.html`
- **Pages**: Edit markdown files in the root directory
- **Blog Posts**: Add markdown files to `_posts/`
- **Projects**: Edit `_data/projects.yml`
- **Services**: Edit `_data/services.yml`

### Styling

- Main styles: `_sass/main.scss`
- Customize colors, fonts, and spacing in the SCSS variables

## Deployment

### GitHub Pages

1. Push your code to a GitHub repository
2. Go to Settings > Pages
3. Select your source branch
4. Your site will be live at `username.github.io`

### Other Platforms

This site can be deployed to:
- Netlify
- Vercel
- Cloudflare Pages
- Any static hosting service
